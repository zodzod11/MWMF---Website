# Women Maternal Wellness Foundation — V1 Website

A modern, accessible, responsive website for a Greater Boston maternal health nonprofit.

## Quickstart

```bash
pnpm install
pnpm dev        # → http://localhost:3000
pnpm build      # production build
pnpm typecheck  # TypeScript check
```

## Stack

Next.js 16 App Router · TypeScript strict · Tailwind CSS 4 · Zod · Lucide icons
